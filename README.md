# PTL
PTL est un projet visant à concevoir un logiciel qui affiche des graphiques à partir de données (ex. mesures, exports CSV/JSON, logs, etc.).
L’objectif : offrir une visualisation claire, rapide et réutilisable.

### 🚀 Objectifs

- Importer des données (CSV/JSON).
- Générer un graphique en nuage de point 
- Permettre un filtrage et une sélection de période.
